# 1D Heat Source Inversion (JAX, no neural nets)

Baseline implementation of a PDE-constrained inverse problem in pure JAX. The goal is to recover a spatial heat source `s(x)` from synthetic observations generated by the 1D heat equation with Dirichlet boundaries.

## Problem setup
- PDE: $u_t = \kappa u_{xx} + s(x)$ on $x \in (0,1)$, $t \in (0,T]$
- Boundary conditions: $u(0,t) = u(1,t) = 0$
- Initial condition: $u(x,0) = 0$
- Spatial discretisation: uniform grid with interior unknowns (Dirichlet nodes removed) and second-order central finite differences.
- Time stepping: implicit Euler with step $\Delta t = T / N_t$. Each step solves a tri-diagonal system via a Thomas algorithm implemented with `lax.scan`.

## Repository layout
- `heat_inverse.py`: end-to-end script that synthesises data, solves the inverse problems (Experiments A/B/C), prints diagnostics, and writes six PNG figures.
- `heat_inverse_demo.ipynb`: annotated notebook version with narrative commentary, mirroring the script while referencing the PyTorch baseline from arXiv:2408.12404 and our team prototype.
- `requirements.txt`: minimal CPU stack (`jax`, `jaxlib`, `numpy`, `matplotlib`).
- `.gitignore`: ignores virtualenv artifacts, caches, and generated plots.

## Running
```bash
export JAX_PLATFORMS=cpu  # enforced in code as a fallback
python heat_inverse.py
```
Outputs:
- console: relative error and wall-clock time per experiment
- figures (root directory): `exp?_loss.png`, `exp?_source.png`

## Implementation notes
- CPU-only execution is forced via `JAX_PLATFORMS=cpu`, avoiding Metal backend crashes.
- The tri-diagonal solve is branch-free inside traced regions (`lax.scan` forward/back substitution) and differentiable.
- Time marching uses `lax.scan` to keep the computation JIT/grad friendly.
- An Adam optimiser (pure JAX math) handles all three experiments; loss and gradients are `jax.jit` wrapped for reuse across iterations.
- `MPLCONFIGDIR` is set to a repository-local folder to bypass locked global cache directories when Matplotlib initialises in sandboxed environments.

## Experiments
The synthetic truth is $s_{	ext{true}}(x) = \sin(2\pi x)$. Observations are generated once per run using the forward model.

| Experiment | Data | Regularisation | Optimiser settings |
|------------|------|----------------|--------------------|
| Exp-A | full field at final time $t = T$ | $\lambda = 10^{-4}$ | Adam, lr=1.5, 3000 iters |
| Exp-B | 16 spatial sensors at final time | $\lambda = 10^{-5}$ | Adam, lr=0.4, 4500 iters |
| Exp-C | full field at $0.3T, 0.6T, T$ | $\lambda = 10^{-4}$ | Adam, lr=1.2, 3000 iters |

Noise level: Gaussian with standard deviation `0.001` applied to every observed quantity.

Exp-B additionally marks sensor locations on the source plot (black crosses). Loss curves are drawn on a semi-log scale for easier convergence inspection.

## Extending
- Modify grid/step counts at the top of `main()` (e.g. increase `Nx`, `Nt`, or change `kappa`).
- Tweak `noise_std`, regularisation weights, or optimiser hyperparameters for different regimes.
- Swap in alternative optimisers (e.g. `jaxopt.LBFGS`) by replacing `run_adam` — the loss/grad functions are JIT-ready.
